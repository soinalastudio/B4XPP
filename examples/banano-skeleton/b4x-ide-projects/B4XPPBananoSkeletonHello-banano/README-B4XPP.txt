BANano Web / PWA project generated by B4X++.

1. Open B4XPPBananoSkeletonHello.b4j in B4J.
2. Make sure BANano and BANanoSkeleton are installed in the B4J Additional Libraries folder.
3. Run the project from B4J. BANano.Build(File.DirApp) will transpile the app to Objects/B4XPPBananoSkeletonHello/ with index.html, CSS and JavaScript files.
4. Edit the .bx sources in src-b4xpp and run B4X++: Sync #Project to regenerate.
